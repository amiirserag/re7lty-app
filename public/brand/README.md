# re7lety App Icon

Eye of Horus (Wadjet) mark — protection / vision / journey — modernized for luxury automotive.

## Files

| File | Use |
|------|-----|
| `public/brand/re7lety-app-icon.png` | Master 1024×1024 App Store / marketing |
| `public/brand/re7lety-app-icon.svg` | Vector master |
| `public/favicon.svg` | Browser favicon |

## Palette

- Background: `#050505`
- Lapis: `#1B3A6B` → `#3D6DB5`
- Gold: `#C9A227`
- Optional accent: `#FF3548`

## iOS

In Xcode Asset Catalog, add `AppIcon` and drop the 1024 PNG (and generated sizes). No text on the icon.
